# Diagnose the result with the evidence available

Start with the consequential visible question. The overview shows a region that did not convert, a missing silhouette or an identity problem; an event involving contact, turn, occlusion or response needs consecutive frames spanning that event. Look first at what you did not describe, then at each person, held prop and contact, then the first and last second ([worst second](../experience/curated/entries/P-worst-second.md)). The [complete-event guide](OBSERVE_EVENTS.md) describes pagination and coverage.

Read Critic's reason and cited evidence beside the original request. The [shared operating reference](OPERATING_REFERENCE.md) explains common report fields and review-focus arguments. Check the report's reading of the task against the request and the video; a judgment of what to preserve is yours to weigh against the recast ([moment](../experience/curated/entries/P-moment.md)).
