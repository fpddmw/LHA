# Express a construction and choose the input that supports it

The [prompt-writing guide](PROMPT_WRITING.md) is included in every Planner call. Use it to turn the design, viewed frames, relevant readings and review findings into the visible relationships expressed in `generate.prompt`.

Describe each plane as the target medium builds it ([every plane](../experience/curated/entries/P-every-plane.md)), give each source element a specific counterpart ([counterparts](../experience/curated/entries/P-counterparts.md)), and write the medium's construction rules ([medium logic](../experience/curated/entries/P-medium-logic.md)). Keep identity wording short ([identity](../experience/curated/entries/P-identity.md)).

The selected input determines which information the next attempt can use. The source holds the people, layout and camera; a candidate holds the world built so far. Choose the one that holds what the next change needs. For Bernini, read [chain drift](../experience/curated/entries/B-chain-drift.md) and the [renderer profile](../experience/curated/renderers.md). On Bernini, also read the [text budget](../experience/curated/entries/B-text-budget.md) and [partial conversion](../experience/curated/entries/B-partial-default.md) accounts before writing a long prompt.

The [shared operating reference](OPERATING_REFERENCE.md) explains renderer input validation and submission counting.
