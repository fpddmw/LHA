# EX-input-conditioning: Choose the visual conditions the next realization needs

Version: 1. Status: draft; heterogeneous historical observations and conditioning interpretation. Scope: recorded Bernini/Ditto setups; no randomized route comparison. Reworks I1/I2/I3 and the useful distinction in R5/I4.

**An editing input supplies both useful achievements and existing losses.** Source input carries original identity, structure and motion evidence. A candidate can carry a partially realized visual direction that the source lacks. The relevant question is which of those conditions the proposed change needs.

## Different routes test different propositions

In Bernini 024, editing v1 extended an existing glitch treatment; its historical independent record preferred v2 under the recorded preservation/style reading. The next source restart attempted to regain facial/handset detail and express a broader displacement treatment, yet its result was weaker on that record. This does not show that source restarts are intrinsically worse: the proposed realization also changed, and the desired actual image displacement remained unconfirmed.

In the study task, replacing an authored robe with fitted clothing recovered visible seating according to the online review. All attempts used source input. This supports reconsidering the conflicting realization, not attributing recovery to a route that was never varied.

In Ditto 027, editing v2 with explicit position and proportional descriptions produced a reported additional dome rather than correcting the existing small landmark. A candidate can support stylistic continuation while failing to bind a geometric correction to the intended instance.

## Implication for input choice

Relate the input to the proposed realization: which needed visual information is present, which useful effects would have to be regenerated, and which existing defect would be inherited? An older candidate can be relevant for these reasons even when it is not the best current delivery. Keep the best delivery separately while exploring.

Continuing a candidate is a plausible route for compatible additions when it already supplies useful appearance. Returning to source is plausible when the proposal needs source evidence that was lost, especially if the realization also addresses the cause of that loss. Neither route guarantees recovery. Repeating the same failed realization from a cleaner input can reproduce the same conflict.
