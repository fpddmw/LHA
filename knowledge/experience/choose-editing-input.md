# Choose an editing input

[Experience entrance](curated/README.md) · [Understand and revise](../creative-loop/UNDERSTAND_AND_REVISE.md)

Choose the input that supplies the visual information needed by the next proposal. A candidate with useful styling is a strong starting point when the remaining work can build on it. When a key identity, action or structure has been lost, inspect an earlier candidate or the source that still contains it. Keep the proposed delivery separate from the next editing input.

This page routes an input decision to its supporting material:

| Decision | Read for |
|---|---|
| The latest result has a consequential defect | [Understand and revise](../creative-loop/UNDERSTAND_AND_REVISE.md): locate the gap, compare retained alternatives and decide what another attempt offers |
| A change affects an activity or object relationship | [Video meaning](../guides/meaning.md): identify what makes the activity recognizable and which changes the request permits |
| The input is suitable but the proposed alteration is unclear | [Express edits](express-edits.md): describe the wanted arrangement for the actual input |
| A renderer-specific preference could settle the route | [Experience entrance](curated/README.md): find approved experience and its supporting cases when available |

These starting preferences are design guidance. The [October 29 Bernini record](../model-experience/bernini-r.md) compares independent prompt conditions; it supplies prompt observations rather than a measured advantage for either editing route. Candidate ancestry and the actual submitted prompt provide the record for interpreting later route outcomes.
