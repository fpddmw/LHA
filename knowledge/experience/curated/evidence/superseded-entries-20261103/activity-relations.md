# EX-activity-relations: Organize the activity around the requested world

Revision 4. Approved for use; goal-directed semantic revision authorized on 2026-11-02.

**Choose the event the requested result should express, then organize its participants, objects and responses. Preserve the source activity when it serves that goal; reconstruct its purpose and causal relationships when the requested world changes what the characters are doing.**

## Decide which relationship deserves continuity

Source footage provides people, framing, movement and a particular interpretation of that movement. These layers can contribute differently to a new proposal. A medium change can retain a conversation while altering how it is drawn. A narrative reconstruction can reuse an approach, offered hand or opposing movement for a new exchange. Develop why the characters act and how the other participant responds, using the source as performance material.

The historical F001 Planner made basketball choreography a core preservation requirement. A later Planner read the activity/conflict accounts and again kept basketball while assigning Wuxia to costume and scenery. In the user's clarified world-reconstruction goal, that commitment kept the old event in place. Read the [case interpretation](../evidence/semantic-goal-review-20261102.md) before treating those preservation attempts as a model task solution.

## Object inventories leave both old and new events open

F003 kept a standing person, microphone and seated guitarist, but directed the microphone toward the standing person's own mouth. F005 produced casino-like materials while reorganizing the mahjong apparatus. These are useful observations about how a venue can reorganize roles. Whether the change is a loss depends on the target event. For a retained performance, the microphone recipient is decisive; for a newly authored performance, the model must establish the new relationship coherently.

Give the target activity a discriminating relation rather than a list of nouns. Describe who initiates, what the action affects, and how the exchange develops where these distinctions make the event readable. Develop the new world's material and spatial expression around that relationship. A ceremonial exchange, a staged performance and a competitive encounter can use similar poses with different purposes; choose from the current request and shot.

## Allocate change to the event that matters

When mahjong remains the requested activity, preserve its working apparatus and player relationships while transforming the room and table exterior. F005 v1 already named the felt, central mechanism and tiles; v2 made this scope division sharper and the saved review found a more recognizable apparatus, though gameplay motion still failed. The useful lesson is role-aware allocation, not a general instruction to preserve every source object.

F003 v2 named the intended recipient and still damaged the performance. Once a required relationship is clear, reconsider competing staging, costume or input before adding a longer recital. If the relationship was your own unnecessary commitment, revise that commitment instead. [Semantic reconstruction](semantic-reconstruction.md) explains this earlier choice; [object continuity](object-continuity.md) develops continuity after the participant's role has been chosen.
