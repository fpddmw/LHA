# Experience for video design and revision

Fourteen reviewed accounts connect scene conditions to concrete preferences and explanations. The user authorized this version for the three-arm experiment on 2026-11-01. Read a relevant summary, then the full account and linked evidence when they can improve the decision.

## Start with the condition that matters

For renderer-specific starting preferences, open [Bernini](renderers.md#bernini) or [Ditto](renderers.md#ditto). For a task or result question, use the corresponding account below.

| Question | Judgment and entry |
|---|---|
| Why did a visually successful addition make the action unreadable? | [EX-design-conflict](entries/design-conflict.md): When a design hides the contacts that make the action readable, reshape or relocate that design before adding preservation clauses. Realize user-required features around the action. |
| Why do the right people and objects still perform a different event? | [EX-activity-relations](entries/activity-relations.md): When retaining an event under a new genre, anchor who acts on whom and give the genre concrete visual scope. A preserved object inventory can still permit the wrong activity. |
| Why did more accurate person descriptions fail to preserve identity? | [EX-instance-identity](entries/instance-identity.md): For identity-sensitive edits, favor an input with the right individual and reduce competing reconstruction around the person. Keep identity wording concise while preserving explicit costume requirements. |
| Why did a correctly named object multiply during an action? | [EX-object-continuity](entries/object-continuity.md): For existing motion, favor concise source-linked object roles over unnecessary choreography. Inspect retrieval, occlusion and release before responding to duplication with more repetitions of one. |
| What does a focused revision actually need to change? | [EX-connected-scope](entries/connected-scope.md): Group changes by visual dependency: a window, view and reflections can be one coherent edit. Separate unrelated repairs when they need different inputs or explanations. |
| Which source or candidate supplies what the next proposal needs? | [EX-input-conditioning](entries/input-conditioning.md): Continue a useful candidate when the next transformation builds on its achievements. If a central relationship is lost, favor the source or an earlier intact candidate and reconsider the transformation. |
| Did the proposed alternative actually change the failed operation? | [EX-realization-change](entries/realization-change.md): After repeated explicit failure, prioritize changed realization or conditioning over stronger synonyms. Direct specification is more promising when the decisive relation was genuinely missing. |
| Why did the correct effect appear on the wrong part? | [EX-part-binding](entries/part-binding.md): For an effect on the wrong part, describe the intended carrier in contrast to its neighbor. Anchor shape repair to the existing instance; consider an earlier intact input when duplication appears. |
| What visual state replaces the unwanted artifact? | [EX-wanted-state](entries/wanted-state.md): Lead correction with a positive visual replacement and resolve conflicts with the surrounding design. Use short exclusions to disambiguate that arrangement. |
| What does style knowledge add beyond a genre label? | [EX-style-realization](entries/style-realization.md): Choose a coherent visible system for broad style requests. For detailed requests, check required construction separately from convincing ornament and atmosphere. |
| Why does the scene have theme cues but remain the old place? | [EX-environment-replacement](entries/environment-replacement.md): If theme cues appear but the old place persists, remap its defining surfaces, boundaries and sightlines. Reassess input and realization when that mapping was already explicit and failed. |
| Why are lamps and glows present without the intended atmosphere? | [EX-lighting-integration](entries/lighting-integration.md): If lamps appear without atmosphere, describe receiving surfaces, fill and reflections. Separate facial illumination from the background cast when both matter. |
| Did the design persist, and did the original event persist? | [EX-time-binding](entries/time-binding.md): Inspect the turns, occlusions and interactions that can undo an attractive opening. Favor delivery for incidental drift; give timing further attention when it carries the requested event. |
| Is a repaired complaint enough to justify another attempt or a final choice? | [EX-continuation-value](entries/continuation-value.md): Favor delivery when the central request is met. Spend another attempt on an important gap with a concrete improvement basis, and compare with the best retained answer. |

The style library supplies visual relationships and alternatives; experience helps judge their fit to the source and renderer. Read the relevant account for its explanation, then follow evidence when it can change the decision.
