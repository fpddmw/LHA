# Selected evidence for the three Skill categories

This snapshot accompanies the Feishu Skill document. It preserves selected existing records without rerunning a model.

- Six completed planning outputs: narrow robe recoloring, cyber-xianxia, storybook, space-station table tennis, etching, and glitch art. Their proposal and exact prompt files are included.
- Storybook single-generation outputs: Bernini and Ditto each executed the earlier model-led Planner prompt. Input and result records are included; the native videos are embedded in the accompanying Feishu document.
- Direct-prompt pre-experiment: Bernini 041 long_keep, included as the actual parent of the selected route experiment.
- Fixed-route pre-experiment: Bernini 041 incremental round 2. The selection record is an online critic assessment plus the experiment's fixed acceptance rule, not a final independent evaluation.
- Continuous Planner: the recorded first two knowledge-reading operations and first generation request from 041_live. These events demonstrate actual reading and submission; this snapshot does not assert a completed continuous-loop result.

The fixed-route experiment and the continuous Planner are different implementations. Formal paired evaluation and knowledge ablation are handled separately. The four selected native videos are provided in the accompanying Feishu document; this repository snapshot contains their input/result records. This is not the full experiment collection.

Existing source paths and records retain their original provenance. Run tools, credentials, and unrelated logs are not included.
