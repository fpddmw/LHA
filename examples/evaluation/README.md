# Evaluation examples

`041_short.card.json` 和 `041_long.card.json` 是已用于开发的真实题目评价卡。
源视频保存在仓库的 `benchmark_data/main/041/041.mp4`，不在这里重复复制。

- 短题仅要求儿童绘本风格，保留开放设计空间。
- 长题逐项加入原始需求中的暖色粉彩、铅笔轮廓、水彩、阴影和纸纹。
- 两张卡保留同一主体／行为及物件检查结构；书写动作需要连续证据。
- `split=development` 明确记录本题已经参与提示词和 planner 开发。
- 卡的签名与审阅身份已保存。修改后用 `freeze` 生成新签名，输出放新目录。

示例不含生成模型成绩。运行方法和输入格式见 [评价协议](../../docs/evaluation-protocol.md)。
