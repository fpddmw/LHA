# Goal-directed semantic adaptation: knowledge maintenance plan

Date: 2026-11-02. The user authorized full local revision of the related manuals, experience accounts, discovery summaries and three maintenance Skills. Experiments and real model calls remain paused.

## Intended change

Planner should choose which source meanings serve the requested result, then develop their preservation or reinterpretation. Source identities, framing, movement, interaction roles and literal activity are different creative materials. A world reconstruction can require new behavior and object functions; an appearance treatment can depend on the original activity. The request establishes the purpose. The model chooses a coherent realization rather than following a fixed story or object substitution.

The current accounts already contain some conditional wording, but their titles, navigation, examples and practical defaults overemphasize retaining the source activity. F001 exposes the consequence: a historical Planner promoted basketball choreography to a core requirement; a later Planner read the curated activity/conflict accounts and explicitly chose to retain basketball while relocating the genre to surfaces. Revisions must change those operative judgments and their discovery surfaces, not append a narrow basketball exception.

## Interfaces with the ongoing reconstruction

The new low-to-high scoring definitions distinguish appearance editing from authorized world/narrative reconstruction. Required correspondence and the resulting event guide evaluation; Planner-authored preservation clauses do not add scoring requirements. This pass aligns guidance with that principle without creating a new task-card, classifier, mandatory reasoning form, or changing the evaluator's source-interpretation interface. No task's independent evaluation plan or live final scores are injected into its Planner context. Reviewed development interpretations enter only later knowledge snapshots.

Current experiment manifests and snapshots remain versioned under their original content. Editing the active source library prepares later newly frozen runs; it does not migrate an existing task. Common manuals provide the interpretation method to both full and none. Only full receives the empirical account and historical case interpretation.

## Editorial decisions

- Prefer advice that changes a design choice: remove an unnecessary preservation commitment, keep a required relation, replace a conflicting function, or choose a more readable realization.
- Treat source motion as possible performance material. A lifted hand is not permanently a basketball shot, and a new event needs its own readable purpose and progression.
- Inspect the target event's continuity. Object removal authorized by the task differs from incoherent disappearance during an event that still needs it.
- Simplify dependencies that do not serve the task. Natural occlusion can serve a design; a hidden required action still needs evidence. Do not recommend exploiting sparse judging.
- Keep original style sources and empirical observations. Revise their interpretation and use when historical goals were wrong. No prescribed duel, artifact, costume cut or universal motion-preservation rule is introduced.

### Before and after

| Surface | Previous operative guidance | Revised guidance |
|---|---|---|
| Design manual | Separate requested changes, source relationships and creative additions. | Choose correspondence across identity, framing, movement, roles and activity. World reconstruction can need a new event even without a supplied script. |
| Activity relations | For a retained event, express the new genre through surfaces, clothing, architecture and light. This dominated the practical advice and examples. | Decide the target event, then organize participants, functions and responses. Preserve a required activity or reinterpret an obsolete purpose. |
| Design conflict | Reshape a costume/prop/light treatment when it covers an activity's necessary contact. | First remove an unnecessary preservation commitment. When both design and action are required, stage them compatibly. |
| Object continuity | Keep an existing prop's continuous role through retrieval, occlusion and release. | Establish the target participant and event, then inspect continuity. An authorized replacement and an incoherent disappearance are different outcomes. |
| Input and continuation | Favor intact source relationships when an activity appears damaged. | Prefer input evidence useful to the target. Retain achieved adaptation; recover source relations only when the task still needs them. |
| Environment and style | Remap surfaces, openings and sightlines; develop a visible style system. | Also examine functions and event logic that can keep the old scene in place under new materials. |
| Maintenance | Explain intervention differences and their outcomes. | Examine the objective first, retain attributed observations, and revise lessons built on a mistaken objective. Trace how a summary or full passage influenced the submitted action. |
