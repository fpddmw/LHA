# 实验总览

## 对照回答什么问题

| 方法 | 输入与行为 | 主要用途 |
|---|---|---|
| direct | 原始提示词直接生成 | 基础对照 |
| pe-loop | 固定增强、生成、Critic 反馈循环 | 增强流程及其迭代收益 |
| full | 有经验的 Planner 迭代编辑 | 完整方法 |
| none | 无经验的同设置迭代编辑 | 经验收益对照 |

full 与 none 使用项目既定知识范围区分；“无经验”不等于没有通用风格资料。比较时保持源视频、原始任务、渲染器及生成设置可比，并记录迭代或采样预算。首轮和最终选中输出分别用于研究迭代收益。

主实验四组 direct、pe-loop、none、full 均覆盖 67 条任务；PE 最多 4 次、Planner 最多 4 次，每个长／短条件最多 13 次生成。40／27 只用于 RSI：经验积累嵌入无经验组前 40 条，后 27 条关闭维护；全量有经验组读取固定累计经验。独立 Critic 为主实验，Planner 自评为追加消融。PE Loop 与 Planner Loop 的首轮直接复用为单次结果。旧 `pe` 单次增强、`planner-once` 和 `direct-best-of-n` 保留为显式选择的补充对照；新旧 PE 的模型与模板记录分别保留。[模式切换与恢复](../pe-loop.md)。

## 当前分工和数量

同事：Bernini PE 134 条、Ditto PE 134 条，各为 67 源视频 × short/long。Bernini 使用官方增强模板；Ditto 使用项目适配模板，不能标为 Ditto 官方 PE 实验。

我们：对应 Bernini Direct；Planner / RSI 结果由完整实验环境产生后补交。这里的数量是计划位置数，不表示已经全部生成。Ditto 目前仅有 PE 计划；要测 Ditto 的增强收益还需同条件 Ditto Direct。跨渲染器比较同时包含底座差异。

两种 PE 都以对应原始提示词出发，分别调用增强模型；增强文本可能不同。若研究固定增强文本下的渲染器差异，需要另立实验并复用同一增强文本。

## 文件交接链

```text
benchmark.zip + 对应生成工具包 + 自备权重/API
    → 生成结果目录（plan.json / runtime.json / cases/）
    → 导入 Bernini 或 Ditto 专属结果库
    → 冻结独立评分配置
    → 用户提供 API / 预算后正式评分
    → index.html / results.json / 原始证据与调用记录
```

请完整交回结果目录。评分导入会验证当前源任务、原始提示词和视频哈希，只有 mp4 不足以验证生成工具包收据。生成方法的内部提示词和在线 Critic 反馈不充当独立评分要求。

## 数据使用

当前清单为67个源视频：训练40、测试27，不设验证集；视频内容未变，长短提示词沿用已审阅版本。当前四组主实验使用 test 的54个长短条件，训练集含80个长短条件。原有 Direct／单次 PE 交接按新版可覆盖134个条件，具体以各批次 plan 为准。长短条件分别报告，不把长提示词的细节作为短提示词的隐藏答案。报告有效样本数、缺失、失败、未知和模型版本。

只有 Direct / PE 输出也可独立评分；比较 Planner 必须有实际 Planner 生成视频。完整经验与迭代分析还需要 none 对照、首轮与最终选中输出、候选及选择记录。
