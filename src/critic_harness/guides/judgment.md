# Applying judgment to video edits

Status: initial common-sense guidance informed by the documented Bernini probe. These are interpretation aids, not experimentally established route advantages. Formal benchmark standards have their own frozen versions.

## User intent, semantic roles and authorized appearance

Read the request at its actual specificity. A short children's-storybook request can be realized with pencil, watercolor, cut-paper or another coherent illustration treatment. Warm colors, watercolor and added plot are not automatically required. A detailed request for blue light on the table perimeter names a location: blue light on supports does not fully satisfy it.

Recognize entities, roles, relations and events before interpreting small drawing differences. A simplified pen can retain its category and writing role. An object drawn like a pencil may indicate a category change, or may be unresolved if the tip is too small. A cropped close view can distinguish these possibilities. A hidden object is not automatically absent.

For 041, distinguish writing continuing, tool-to-page contact, tool category, binding structure and the relation between notebook and separate sheet. Incidental binding detail normally remains a detail; an explicit user demand can elevate it. If the notebook remains but its binding moves, describe that exact partial preservation. If a separate sheet becomes an attached page, describe the lost two-object relation. If the boundary cannot be established, use unknown. These examples define questions, not labels for unseen outputs.

For table tennis, distinguish player identity, sides, paddles, table/net relations and movement. A space-station setting does not compensate for a failed explicit face-preservation request. A ball missing in a sparse frame may be occluded, between samples or unresolved; inspect corresponding source/output intervals before diagnosing a disappearance or changed trajectory.

## Style and aesthetic quality

Style attainment asks whether the requested visual language is expressed, including its visible extent and stability. Coordination asks whether the output's palette, lighting, materials and focal hierarchy work together. A consistent photographic image can be coordinated while failing an illustration request; report both facts plainly.

Use task-specific evidence for score anchors. For storybook style: absent illustrative treatment is near 1; a few isolated drawing cues near 2; clear coherent illustration near 3; fully integrated, scene-appropriate treatment near 4. These are qualitative anchors, not a mandated recipe. Decimal interpolation needs an observable reason and does not establish reliable 0.1 discrimination.

A source-inherited crop can constrain overall composition. Identify it as inherited before suggesting an editing defect. A semantic error can also harm readability, but explain the distinct visible effects instead of copying the same penalty into every dimension. Scene-specific design values a useful adaptation of actual subjects, space and activity. Completing specified details or adding unsupported objects is not automatically originality.

## Feedback and revisions

Evaluate candidate versus original task, actual input and alternative separately. A stronger style with a new object error is a tradeoff, not an automatically better or worse candidate. A useful parent need not be the highest-rated overall candidate. The Critic describes these differences; the Planner chooses how to use them.

Failure causes remain hypotheses until compared evidence supports them. The model may misplace an explicitly and correctly worded attribute. Longer wording is not inherently better. Preserve successful effects in the feedback so a later edit has a clear account of what is worth retaining.
